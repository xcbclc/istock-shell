# 命令规范

`iStock Shell` 是一个基于命令驱动的金融数据分析终端。本规范参考了 POSIX 和 GNU 命令行标准，结合项目实际特性，定义了命令的结构、语法、解析规则及最佳实践。

## 1. 命令基本结构

一条完整的命令通常由 **命令名**、**子命令**、**选项（Options）** 和 **参数（Arguments）** 组成。

### 1.1 通用语法

```bash
<命令名> [子命令] [选项...] [参数...]
```

### 1.2 组成部分详解

| 组件                    | 定义                     | 规范                                                     | 示例                            |
| :---------------------- | :----------------------- | :------------------------------------------------------- | :------------------------------ |
| **命令名** (Command)    | 指示执行特定操作的标识符 | 建议使用英文单词或中文拼音首字母缩写。应简短且具描述性。 | `lsfbsj` (历史分笔数据) |
| **子命令** (Subcommand) | 主命令下的功能分支       | 跟在主命令之后，以空格分隔。             | `tb bt` (图表-饼图)             |
| **选项** (Options)      | 修改命令行为或指定配置   | 以 `-` 或 `--` 开头，分为**开关型**和**值型**。          | `-dw`, `--单位`               |
| **参数** (Arguments)    | 命令操作的对象           | 位置参数，顺序敏感。                                     | yyjr akshare              |

## 2. 选项与参数规范

### 2.1 选项

选项用于调整命令的执行逻辑。

- **前缀规范**：
  - **短选项**：使用单连字符 `-` 后跟单个字母或拼音首字母，如 `-dw`。
  - **长选项**：使用双连字符 `--` 后跟单词或汉字，如 `--单位`。
- **类型**：
  - **开关型 (Boolean)**：不需要值，存在即为 `true` 或 给定的默认值。
  - **值型 (Value)**：后接具体的值。例如 `-dw 亿` (单位：亿)。

### 2.2 参数

参数是命令执行的必要输入。文档描述使用尖括号 `< >` 表示，必须提供。例如 `tb txt`。
- **类型校验**：系统支持对参数进行严格的类型检查。
  - `string`: 字符串
  - `number`: 数字（支持 `min`, `max` 范围校验）
  - `boolean`: 布尔值
  - `regexp`: 正则表达式

### 2.3 复杂数据类型

对于复杂的参数值（如 JSON 对象或包含空格的字符串），需遵循以下规则：

- **字符串**：如果包含空格，**必须**使用双引号 `"` 或单引号 `'` 包裹。
  - 示例：`echo "Hello World"`
- **JSON**：可以直接作为参数传递，建议使用紧凑格式（无空格）或用引号包裹。
  - 示例：`-config '{"theme":"dark"}'`

## 3. 特殊语法与高级特性

### 3.1 管道 `|`

将前一个命令的**输出结果**作为后一个命令的**输入参数**，实现数据流的链式处理。

- **示例**：
  ```bash
  # 获取 A 股数据，然后过滤出涨幅大于 5% 的股票
  hq ag | gl "涨幅 > 5"
  ```

### 3.2 组合命令 `()`

使用圆括号对命令进行分组，控制执行顺序或逻辑组合。

- **示例**：
  ```bash
  (echo A && echo B) | grep A
  ```

### 3.3 关键字命令 (Key Command)

用于特定场景的快捷操作指令，格式为 `关键字:内容`。

| 关键字 | 用途                               | 示例              |
| :----- | :--------------------------------- | :---------------- |
| `:`    | 别名或快捷指令                     | `:茅台行情`       |
| `ai:`  | 唤起 AI 助手进行自然语言对话或分析 | `ai:分析茅台走势` |

## 4. 最佳实践

### 4.1 命名建议

- **命令名**：使用小写字母或拼音首字母，保持简短且具有语义。
- **选项名**：保持一致性。

### 4.2 参数设计

- 将最常用的参数设计为**位置参数**，次要参数设计为**选项**。
- 避免过多的位置参数（超过 3 个），这会降低命令的可读性和易用性。

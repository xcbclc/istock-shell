# 命令规范 (Command Specification)

`iStock Shell` 是一个基于命令驱动的金融数据分析终端。本规范参考了 POSIX 和 GNU 命令行标准，结合项目实际特性，定义了命令的结构、语法、解析规则及最佳实践。

## 1. 命令基本结构 (Basic Structure)

一条完整的命令通常由 **命令名**、**子命令**、**选项（Options）** 和 **参数（Arguments）** 组成。

### 1.1 通用语法

```bash
<命令名> [子命令] [选项...] [参数...]
```

### 1.2 组成部分详解

| 组件                    | 定义                     | 规范                                                     | 示例                            |
| :---------------------- | :----------------------- | :------------------------------------------------------- | :------------------------------ |
| **命令名** (Command)    | 指示执行特定操作的标识符 | 建议使用英文单词或中文拼音首字母缩写。应简短且具描述性。 | `lsfbsj` (历史分笔数据), `help` |
| **子命令** (Subcommand) | 主命令下的功能分支       | 跟在主命令之后，以空格分隔。支持多级子命令。             | `tb bt` (图表-饼图)             |
| **选项** (Options)      | 修改命令行为或指定配置   | 以 `-` 或 `--` 开头，分为**开关型**和**值型**。          | `-v`, `--verbose`               |
| **参数** (Arguments)    | 命令操作的对象           | 位置参数，顺序敏感。                                     | 文件路径、股票代码              |

## 2. 选项与参数规范 (Options & Arguments)

### 2.1 选项 (Options)

选项用于调整命令的执行逻辑。

- **前缀规范**：
  - **短选项**：使用单连字符 `-` 后跟单个字母或拼音首字母，如 `-v`、`-dw`。
  - **长选项**：使用双连字符 `--` 后跟单词或汉字，如 `--verbose`、`--单位`。
- **类型**：
  - **开关型 (Boolean)**：不需要值，存在即为 `true`。例如 `-r` (recursive)。
  - **值型 (Value)**：后接具体的值。例如 `-n 10` 或 `--name "iStock"`。

### 2.2 参数 (Arguments)

参数是命令执行的必要输入。

- **必选参数**：使用尖括号 `< >` 表示，必须提供。例如 `<file>`。
- **可选参数**：使用方括号 `[ ]` 表示，可以省略。例如 `[output]`。
- **类型校验**：系统支持对参数进行严格的类型检查。
  - `string`: 字符串
  - `number`: 数字（支持 `min`, `max` 范围校验）
  - `boolean`: 布尔值
  - `regexp`: 正则表达式

### 2.3 复杂数据类型

对于复杂的参数值（如 JSON 对象或包含空格的字符串），需遵循以下规则：

- **字符串**：如果包含空格，**必须**使用双引号 `"` 或单引号 `'` 包裹。
  - 示例：`echo "Hello World"`
- **JSON**：可以直接作为参数传递，建议使用紧凑格式（无空格）或用引号包裹。
  - 示例：`-config '{"theme":"dark"}'`

## 3. 特殊语法与高级特性 (Advanced Features)

### 3.1 管道 (Pipeline) `|`

将前一个命令的**输出结果**作为后一个命令的**输入参数**，实现数据流的链式处理。

- **示例**：
  ```bash
  # 获取 A 股数据，然后过滤出涨幅大于 5% 的股票
  hq ag | gl "涨幅 > 5"
  ```

### 3.2 组合命令 `()`

使用圆括号对命令进行分组，控制执行顺序或逻辑组合。

- **示例**：
  ```bash
  (echo A && echo B) | grep A
  ```

### 3.3 关键字命令 (Key Command)

用于特定场景的快捷操作指令，格式为 `关键字:内容`。

| 关键字 | 用途                               | 示例              |
| :----- | :--------------------------------- | :---------------- |
| `ai:`  | 唤起 AI 助手进行自然语言对话或分析 | `ai:分析茅台走势` |
| `ss:`  | 全局搜索（Search）                 | `ss:半导体`       |
| `:`    | 别名或快捷指令                     | `:my-alias`       |

## 4. 解析流程 (Parsing Process)

命令解析由 `@istock-shell/command-parser` 核心包处理，遵循以下标准流程：

1.  **Tokenizer (词法分析)**:
    - 将原始输入字符串扫描并分割为 Token 序列。
    - 识别 `command`, `parameter`, `optionKey`, `pipe`, `mention` 等基本单元。
2.  **Parser (语法分析)**:
    - 根据 Token 序列构建抽象语法树 (AST)。
    - 识别命令层级结构、选项关联及管道连接。
3.  **Validator (语义校验)**:
    - 根据命令定义（Schema）检查参数及其类型。
    - 验证必填项、数值范围、正则表达式匹配等。
4.  **Execution (执行)**:
    - 生成可执行的 Command 对象，分发给对应的 Controller 处理。

## 5. 最佳实践 (Best Practices)

### 5.1 命名建议

- **命令名**：使用小写字母或拼音首字母，保持简短且具有语义。
- **选项名**：保持一致性。

### 5.2 参数设计

- 将最常用的参数设计为**位置参数**，次要参数设计为**选项**。
- 避免过多的位置参数（超过 3 个），这会降低命令的可读性和易用性。

### 5.3 帮助信息

- 所有命令都应实现标准的帮助选项（通常是 `-bz`），输出命令的用法说明、参数列表和示例。

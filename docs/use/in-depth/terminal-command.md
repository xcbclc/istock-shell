# 终端命令

在 **iStock Shell** 中，终端命令不仅是简单的文本指令，更是连接用户与海量金融数据的桥梁。通过精心设计的命令体系，用户可以极速获取市场行情、分析数据并生成专业图表。

## 什么是命令？

命令是一串遵循特定语法的文本，告诉 iStock Shell 你想要做什么。这就好比你对助手说了一句“查找当前有哪些应用”，在 iStock Shell 中，你只需要输入类似 `yycz` 的指令。

相比于图形界面（GUI），命令交互拥有以下优势：

- **极速**：键盘操作远快于鼠标寻找菜单。
- **精确**：通过参数精确控制数据范围和格式。
- **组合**：通过管道（Pipe）将多个简单命令组合成强大的工作流。
- **自动化**：命令可以被保存和重复执行。

## 命令结构

iStock Shell 的命令遵循标准的命令行语法，通常由 **命令名**、**子命令**、**选项** 和 **参数** 组成。

```bash
命令名 [子命令] [选项] [参数]
```

### 1. 命令名 (Command Name)

命令的唯一标识。为了方便中文用户，iStock Shell 采用了 **中文拼音首字母缩写** 的命名规范。

- 例如：`yycz` 对应 **Y**ing**Y**ong**C**ha**Z**hao (应用查找)。
- 这种设计让你可以凭直觉猜测命令，无需死记硬背。

### 2. 子命令 (Subcommand)

部分命令包含多个功能模块，通过子命令进行区分。

- 例如：`tb bt` 中，`tb` 是图表（TuBiao）命令，`bt` 是饼图（BingTu）子命令。

### 3. 选项 (Options)

用于修改命令的行为，通常以 `-` (短选项) 或 `--` (长选项) 开头。

- **必选选项**：通常用 `< >` 表示，必须提供值。
- **可选选项**：通常用 `[ ]` 表示，可以使用默认值。
- 例如：`-y 占比` 表示指定 Y 轴字段为“占比”。

### 4. 参数 (Arguments)

命令操作的对象或输入数据。

- 例如：`yyjr akshare` 中的 `akshare` 就是参数，表示要进入 AkShare 应用下面。

## 核心特性

### 1. 智能补全与模糊搜索

记不清命令全名？没关系。

- **自动补全**：输入前几个字母，按下 `Tab` 键，系统会自动匹配相关命令，选择后补全命令。

### 2. 管道操作 (Piping)

这是命令行的灵魂。使用管道符 `|`，你可以将前一个命令的 **输出结果** 直接作为下一个命令的 **输入数据**。

**场景示例**：查询数据 -> 绘制图表

```bash
# 获取某个数据 | 绘制趋势图
gp_lshqsj_dc1 -symbol 600519 -start_date 20150101 -period monthly | tb gplzt -x 日期 -y1 开盘,收盘 -y2 最高,最低
```

### 3. AI 辅助 (AI Integration)

如果你不想记任何命令，可以使用 `ai` 命令直接对话。

- 输入：`ai 帮我看看最近茅台的行情怎么样`
- 系统会通过大语言模型分析你的意图，并尝试调用相关数据命令或直接给出分析建议。

::: warning 注意
上述为概念示例，具体功能现阶段在规划中。
:::


### 4. 别名系统 (Alias)

觉得 `gp_lshqsj_dc1 -symbol 600519 -start_date 20150101 -period monthly | tb gplzt -x 日期 -y1 开盘,收盘 -y2 最高,最低` 太长？你可以为常用命令设置别名。

- 虽然系统默认提供了拼音首字母别名，你也可以自定义更符合你习惯的短语。

## 常用命令类型

- **数据查询类**：如 `yyjr` (应用进入)。用于应用间切换。
- **图表可视化类**：如 `tb` (图表)。将数据转化为 K线图、饼图、折线图等。
- **辅助工具类**：如 `lssc` (历史删除)。删除历史数据并清屏。

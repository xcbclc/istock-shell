`iStock Shell`是一款基于现代Web技术栈的专业金融数据查询终端，设计理念围绕着`简单性、高效率、灵活性以及可定制性展开`。它为用户提供了一个统一的平台，通过直观的命令行交互，即可查询并展示来自多个数据源的金融信息。

## 🚀 技术架构

项目采用现代化的前端技术栈构建：

- **前端框架**：基于 `Svelte` + `TypeScript` 构建，提供类型安全和高性能的用户体验
- **多线程处理**：利用 `Web Worker` 技术实现数据处理与UI渲染的分离，确保界面流畅响应
- **PWA支持**：支持渐进式Web应用特性，无需安装任何额外软件
- **模块化设计**：采用装饰器驱动的模块化架构，支持依赖注入和面向切面编程
- **组件化UI**：内置60+精美组件库，包含数据可视化、表单控件、反馈组件等

## 📊 数据覆盖

目前支持以下金融数据领域：

- **A股市场**：实时行情、历史数据、技术分析、分笔数据等
- **可转债**：实时数据、双低策略、申购信息等
- **房产数据**：成都二手房行情数据
- **投资日历**：新股申购、分红派息、重要事件等
- **网站导航**：财经站点快速访问

## 💡 项目起源

`iStock Shell` 的诞生源于对现有金融数据查询工具痛点的深度思考。在实际投资研究过程中，我们发现：

- **数据分散**：有价值的金融数据散落在各个平台，需要频繁切换网站和工具
- **效率低下**：重复性的查询操作消耗大量时间，缺乏自动化手段
- **体验割裂**：不同数据源的界面和交互方式差异巨大，学习成本高
- **定制困难**：现有工具难以满足个性化的数据分析需求
- **分析局限**：传统工具仅提供数据展示，缺乏AI智能分析和洞察能力

基于这些痛点，我们构想了一个**智能化的金融数据查询终端**：通过命令行界面提供高效的数据访问方式，将分散的数据源整合到统一平台，并计划引入**AI智能分析引擎**，让专业投资者不仅能够快速获取数据，更能获得智能化的数据洞察和投资建议，真正实现从数据查询到智能决策的完整闭环。

## 📡 数据源架构

`iStock Shell`采用模块化的数据源架构，支持多种数据接口的统一管理和调用：

### 主要数据源

- **[AKShare](https://akshare.akfamily.xyz/introduction.html)**：主要的金融数据接口，提供股票、期货、基金等全面的金融数据
- **集思录**：专业的可转债数据源，提供实时行情和策略分析
- **东方财富**：A股实时行情和历史数据
- **新浪财经**：补充的股票数据源
- **地方政务网站**：房产等特色数据源

### 数据处理特性

- **统一接口**：通过ORM层统一不同数据源的访问方式
- **数据缓存**：支持本地缓存，减少重复请求，提升响应速度
- **格式标准化**：自动处理不同数据源的格式差异，提供一致的数据结构
- **错误容错**：智能的数据源切换和错误恢复机制

::: info 关于AKShare
AKShare是基于Python的开源财经数据接口库，提供股票、期货、期权、基金、外汇、债券、指数、加密货币等金融产品的基本面数据、实时和历史行情数据。项目通过API网关的方式集成AKShare，确保数据的实时性和准确性。

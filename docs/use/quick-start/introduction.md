# iStock Shell

`iStock Shell` 是一款 **AI 原生** 的专业金融数据查询分析终端。

它打破了传统金融软件复杂的界面交互模式，采用 **命令驱动 + 自然语言** 的核心设计理念，将分散在各个平台（如 A股、基金、可转债、期货等）的金融数据整合到统一的命令行界面中。融合大语言模型（LLM）的智能分析能力，为您提供极速、深度、个性化的市场洞察。

> **设计理念**：简单性 (Simplicity) · 高效率 (Efficiency) · 灵活性 (Flexibility) · 可定制性 (Customizability)

## 🚀 核心亮点

### 🤖 AI 智能辅助

内置 `ai` 命令，直接与大模型对话。不仅能查询数据，更能对市场行情进行智能解读、风险评估和策略分析，让数据不仅仅是数字，而是可执行的洞察。

### ⚡ 极速命令交互

基于自主研发的命令解析引擎，提供 IDE 级的交互体验：

- **智能补全**：自动提示命令参数，无需记忆复杂指令。
- **模糊搜索**：支持拼音、缩写模糊匹配，快速定位功能。
- **别名系统**：支持自定义命令别名（Alias），打造个人专属快捷键。
- **历史记录**：自动保存操作历史，支持快速回溯与重复执行。

### 📊 全市场数据覆盖

深度集成 [AkShare](https://akshare.akfamily.xyz/) 等开源数据接口，覆盖全品类金融数据：

- **A股市场**：实时行情、龙虎榜、资金流向、历史K线。
- **可转债**：集思录数据、双低策略、申购信息。
- **更多领域**：基金、期货、外汇、宏观经济数据等。

### 🎨 专业可视化与管道

- **图表组件**：内置 K线图、分时图、饼图等 60+ 专业组件。
- **管道操作**：支持 Unix 风格的管道（Pipe）操作，可将一个命令的输出作为另一个命令的输入，灵活组合分析流程。
- **多窗口管理**：支持多标签页并行操作，数据对比更直观。

## 🛠️ 技术架构

项目采用最前沿的 Web 技术栈构建，兼顾高性能与开发体验：

| 技术领域     | 方案选型                    | 优势                                                 |
| :----------- | :-------------------------- | :--------------------------------------------------- |
| **前端框架** | `Svelte` + `TypeScript`     | 极致的编译时优化，零运行时开销，类型安全。           |
| **核心引擎** | `Web Worker`                | 独立的计算线程，确保海量数据处理时 UI 依然丝般顺滑。 |
| **应用形态** | `PWA` (Progressive Web App) | 支持离线访问，可安装到桌面，体验接近原生应用。       |
| **架构设计** | 模块化 + 依赖注入 (IoC)     | 基于装饰器的架构，支持插件化扩展与热插拔。           |

## 📡 数据源生态

我们致力于构建开放、稳定的数据生态：

- **AkShare**: 核心数据底座，提供 Python 接口映射。
- **集思录**: 专注于可转债与低风险投资数据。
- **东方财富 / 新浪财经**: 补充实时行情与资讯。
- **特色数据**: 地方房产行情、投资日历、宏观指标等。

::: tip 开源共建
本项目完全开源，支持开发者通过简单的 API 接入新的数据源或开发自定义命令插件。
:::

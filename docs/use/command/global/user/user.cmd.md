# 全局

## yhdl 用户登录

支持微信扫码登录

### 用法

`yhdl <登录类型>`

### 参数

|   名称   | 描述           |  类型  | 是否可选 | 默认值 | 可选值 |
| :------: | :------------- | :----: | :------: | :----: | :----: |
| 登录类型 | 用户登录的类型 | string |  false   |        |   wx   |

### 命令示例

`yhdl wx`
